## RBAC & Security
- Superset uses SQLite for its internal metadata (`superset.db`).
- There is only one native user configured in Superset: `admin`.
- End users do not have explicit Superset accounts. They authenticate via embedded Guest Tokens (dynamically generated by the backend) associated with the `Gamma` role.
